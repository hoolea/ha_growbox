Набор автоматизаций и UI-карточка для управления гроубоксом в **Home Assistant**.  
Репозиторий включает контроль температуры, влажности, освещения и автоматический полив с уведомлениями.

---

## 📊 Интерфейс (Lovelace UI)

Карточка построена на `vertical-stack` и включает:

- 📷 Изображение гроубокса
- 🌡️ Температура
- 💧 Влажность воздуха
- 🌱 Влажность почвы
- 🔋 Заряд датчика
- ⚙️ Управление устройствами
- 🤖 Список автоматизаций

Используется кастомная карточка:
- `mushroom-template-card`

### Особенности UI:
- Цветовая индикация параметров (green / yellow / orange / red)
- Компактное отображение ключевых метрик
- Быстрый доступ к управлению устройствами

---

## ⚙️ Автоматизации

### ❄️ Охлаждение
**Описание:**  
Включает охлаждение при высокой температуре и выключает при нормализации.

- Включение: ≥ 29°C  
- Выключение: ≤ 28°C  

---

### 🔥 Подогрев
**Описание:**  
Адаптивное управление температурой в зависимости от времени суток (через состояние лампы).

**День (лампа включена):**
- Включение: < 26°C  
- Выключение: > 27°C  

**Ночь (лампа выключена):**
- Включение: < 22°C  
- Выключение: > 23°C  

---

### 💡 Освещение
**Описание:**  
Автоматическое включение и выключение света по расписанию.

- Включение: 09:00  
- Выключение: 00:00  

---

### 💧 Полив
**Описание:**  
Автоматический полив на основе влажности почвы с уведомлениями в Telegram.

#### Логика:
1. Если влажность < 60% → запускается полив
2. Полив длится 15 секунд
3. Через 45 минут выполняется повторная проверка
4. При необходимости — повторный полив

#### Дополнительно:
- Проверка доступности датчиков
- Защита от некорректных значений
- Уведомления:
  - 🌱 начало полива
  - 💧 завершение
  - ⚠️ повторный полив
  - 🚨 ошибки

## 🔌 Используемые сущности

### Датчики:
- `sensor.datchik_temperatury_grouboks_temperature`
- `sensor.datchik_temperatury_grouboks_humidity`
- `sensor.0xa4c1388a2836cbfc_soil_moisture`
- `sensor.0xa4c1388a2836cbfc_battery`

### Переключатели:
- Охлаждение: `switch.rele_grouboks_l1`
- Свет: `switch.rele_grouboks_l2`
- Подогрев: `switch.rele_grouboks_l3`
- Подогрев воды: `switch.rele_grouboks_l4`
- Полив:
  - `switch.unknown_switch_1`
  - `switch.unknown_switch_2`

### Уведомления:
- `notify.telegram_notifier`

## 🚀 Установка

1. Скопируйте автоматизации в `automations.yaml`
2. Добавьте UI-карточку в Lovelace Dashboard
3. Убедитесь, что установлена:
   - `Mushroom Cards`
4. Проверьте соответствие entity_id вашим устройствам
